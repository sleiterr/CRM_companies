This is a learning CRM dashboard built with the Next.js App Router. The project demonstrates a multi-pane admin UI, parallel dashboard routes, and basic forms.

## Quick Start

1) Install dependencies:

```bash
npm install
```

2) Add the environment variable in `.env.local`:

```
NEXT_PUBLIC_PROJECT_TOKEN=your_mockapi_project_token
```

3) Start the dev server:

```bash
npm run dev
```

Open http://localhost:3000
