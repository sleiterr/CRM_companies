title: Components
description: Core UI components and their purpose
---

## Navigation and Layout

- `Sidebar` - left menu for navigating between dashboard and companies.
- `Header` - top bar with page title and profile.
- `Toolbar` - row with inputs and actions (for example, search and a button).

## Tables and Lists

- `CompanyTable` - companies table with column headers.
- `CompanyRow` - company row with status and promotion indicators.
- `SummaryTable` + `SummaryTableHeader` + `SummaryTableCell` - tables for dashboard blocks.

## Stat Cards

- `StatCard` - metric card (gradient or dark theme).
- `DashboardCard` - container for dashboard sections.

## Forms and Modals

- `AddCompanyButton` - opens the add-company modal.
- `CompanyFormModal` - modal window with the form.
- `CompanyForm` - company data form (Formik).
- `InputField`, `LogoUploader`, `Button`, `Modal` - base UI components.

## Interactive Elements

- `SearchInput` - search field with a button.
- `StatusLabel` - badge for company status.
- `MagicButton` - test component to trigger the error boundary.
