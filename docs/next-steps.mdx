description: Ideas for extending the project
---

Below are logical directions to evolve this learning CRM.

## Features

- Add real CRUD for companies and promotions.
- Implement search and filtering in the companies list.
- Add pagination or infinite scroll.

## Architecture and Data

- Move the API layer into a dedicated service or server routes.
- Add form validation (Zod + React Hook Form or Formik + Yup).
- Add caching and client-side state management.

## UX and Security

- Add authentication and roles (admin / manager).
- Use a real user profile in the header.
- Add empty states and skeleton loading for tables.

## Quality

- Add unit tests for utilities and integration tests for pages.
- Set up CI (lint + test).
